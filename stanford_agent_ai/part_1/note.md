# SFT vs RLHF
## Q1: Why can't SFT do alignment? Theoretically it could learn it, right?
**Core:** SFT needs a gold answer to imitate. For alignment, nobody can write
the gold answer. The limit is the training signal, not model expressiveness.
1. **Generation vs. judgment.** SFT needs humans to *write* the ideal response
   → capped at demonstrator quality. RL only needs humans to *rank* two samples
   → cheaper, more reliable, and can exceed the demonstrator.
2. **Undirected negative gradient.** Cross-entropy *does* push non-target tokens
   down (grad on logit j = `p_j − 1{j=target}`), but proportional to `p_j`, not to
   badness — and only at contexts present in the demo data. A bad continuation
   branching off an unseen context gets no gradient at all. RL/DPO push down a
   specific *policy-generated* sequence, weighted by *reward*.
3. **Imitating others teaches hallucination.** SFT targets contain knowledge the
   model lacks → it learns "assert confidently here." When to say "I don't know"
   depends on what *this* model knows; no fixed dataset encodes that. RL scores
   the model's own samples, so it can.
**On "theoretically yes":** true, given infinite data from the optimal aligned
policy — which is exactly what alignment is trying to find. Rejection-sampling
FT (STaR/RAFT) is SFT doing RL's job, but smuggles in **on-policy sampling** +
**a reward function**. The real axis is not SFT loss vs RL loss — it's whether
you have those two things.
## Q2: What's the actual gap, and which tasks need RLHF?
| Axis | SFT-only | +RL |
| --- | --- | --- |
| Adversarial robustness | Refusals brittle, easy to reframe around | Generalizes off-distribution |
| Hallucination | Confidently asserts | Abstention tuned to own knowledge |
| Open-ended helpfulness | Weak in the tail | Large win-rate gains |
| Long-horizon / agentic | Errors compound off-distribution | Trained on own rollouts, recovers |
| Verifiable (math/code) | Can only imitate solutions | Optimizes the checker — biggest gaps today |
| Constraint following | Drifts | Reward encodes constraint exactly |
| Sycophancy / verbosity | Inherits the data | Directly tunable (and reward-hackable) |
Flip side: RLHF often *costs* a little on standard benchmarks ("alignment tax").
Gains concentrate in open-ended and adversarial settings.
**Decision rule**
- Can you write the ideal output? → **SFT**. Can you only score/rank it? → **RL**.
- Fixing a *capability/format* gap → SFT. Fixing a *selection* gap (model can
  produce the good output but picks the bad one) → RL. This is the alignment case.
**SFT is enough for:** domain adaptation, style/tone, structured extraction, classification, distillation. 

Besides, human label can be biased and if human tend to answer "it depends..", "there's lots of perspective..", then the model will also hedge the answer. If the SFT data quality is low, it can even overwrite the pre-training model.

## **Constitutional AI (CAI)** 

 An alignment method (Anthropic, 2022) that replaces per-example human labels with a written set of principles (a "constitution"): the model critiques and revises its own outputs against those principles for supervised training, then generates its own preference comparisons to drive RL (RLAIF instead of RLHF). Human input moves from labeling individual responses to authoring the rules, making alignment cheaper, auditable, and editable.

Steps:
1. Supervised learning: Finetune LLM on data generated by self-critique and revisions
2. RL from AI feedback (RLAIF)
    1. Train a preference model based on LLM (first step) responses and constitution
    2. Finetune the LLM to maximize the preference model

RLHF vs RLAIF: AI can balance harmlessness and helpfulness better.


RLHF/RLAIF align the model to human preference, but human ratings carry no reliable correctness signal — on hard problems humans can't tell right from wrong either, only what sounds right. So that path can't improve reasoning. RLVR replaces the judge with a ground-truth verifier, putting real correctness into the reward for the first time. And since the only reliable way to earn that reward on hard problems is to actually reason well, reasoning gets \*\*amplified\*\* by RL as an emergent means to correctness — it is never rewarded directly.

RLVF (RL verifierable feedback): use verifier to check whether the answer is correct or not

- **RLHF/RLAIF** → the alignment layer: helpful, harmless, tone, instruction-following, refusals
- **RLVR** → the capability layer: math, code, logical reasoning

**Group Relative Policy Optimization (GRPO)** is a reinforcement learning algorithm used to train large language models, famously used in models like DeepSeekMath and DeepSeek-R1. [[1](https://arxiv.org/pdf/2402.03300), [2](https://cameronrwolfe.substack.com/p/grpo), [3](https://snorkel.ai/grpo/)]
